# Детская мебель АМ · Тверь

**Готовый независимый демонстрационный сайт для сообщества «Детская мебель на заказ, г. Тверь».** Создан как предложение компании, не является официальным сайтом и не уполномочен принимать заказы от имени мастерской.

## Быстрый просмотр

После распаковки откройте `preview-offline.html` двойным щелчком. В этой автономной версии стили, изображения и скрипты встроены прямо в HTML. Ссылки меню ведут на другие автономные страницы:

- `preview-offline.html` — главная;
- `preview-catalog-offline.html` — каталог;
- `preview-lookbook-offline.html` — идеи комнат;
- `preview-materials-offline.html` — палитры;
- `preview-planner-offline.html` — конструктор;
- `preview-contacts-offline.html` — контакты.

Для публикации используйте **обычные файлы без `preview-`**: `index.html`, `catalog.html`, `lookbook.html`, `materials.html`, `planner.html`, `contacts.html`, и всю папку `assets/`.

## Как разместить на Vercel

1. Создайте репозиторий на GitHub и загрузите в корень его содержимое этого архива, чтобы `index.html` находился в корне.
2. Откройте Vercel → **Add New → Project** → выберите репозиторий.
3. **Framework Preset: Other**; не указывайте Build Command и Output Directory — проект статический.
4. Нажмите **Deploy** и откройте полученную ссылку.
5. Перед официальным запуском согласуйте фирменный стиль, реальные работы, материалы, сроки, гарантию и контакты с мастерской. После согласования можно убрать `noindex` из `<head>` и запрет индексации в `robots.txt`.

## Файлы и настройка

- `assets/style.css` — оформление и адаптивность.
- `assets/app.js` — фильтры, палитры, модальное окно, живой эскиз и заявка.
- `assets/data.js` — девять редактируемых демонстрационных карточек.
- `assets/scenes/*.svg` — 46 **оригинальных** сцен в девяти компоновках и пяти цветах. Все визуализации условные, не фото реальных работ.
- `assets/favicon.svg` — демонстрационная иконка АМ.
- `previews/` — скриншоты, результаты QA.
- `СООБЩЕНИЕ_ДЛЯ_VK.txt` — текст первого обращения.

## Как работает конструктор

Выбор типа мебели и палитры обновляет SVG-эскиз. Пользователь может указать приблизительную ширину и длину комнаты, возраст ребёнка, нужные модули и комментарий, а также добавить до трёх фотографий JPG/PNG/WebP до 8 МБ. На выходе генерируется готовый текст для копирования и есть ссылка на сообщения VK.

**Фото не уходят на сервер и не передаются автоматически** — пользователь прикрепляет их вручную к сообщению. Сайт не собирает личные данные на сервере и не делает заказ в фоне. Копирование работает через Clipboard API или резервный механизм браузера.
